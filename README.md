# EdgeAI – Hardware-Aware Deep Learning Optimization

## Project Overview
A machine learning software engineering project focused on developing, optimizing, and benchmarking deep learning models for efficient inference on Arm-based devices.

## Objectives
- Train a deep learning image classification model.
- Apply model quantization and pruning.
- Export models to ONNX.
- Compare inference latency, memory usage and model size.
- Develop a C++ inference application.
- Evaluate performance on Arm64 hardware or an appropriate environment.

## Technologies
Python, PyTorch, Torchvision, ONNX Runtime, C++, Linux, Bash and Git.

## Project Status
In development.

## Setup
